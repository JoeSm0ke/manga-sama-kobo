# Manga Sama — Kobo

Une bibliothèque de mangas pilotée depuis une Kobo, avec un pont PC pour préparer les tomes.

## Le projet

Depuis la liseuse, on recherche une série et on demande au PC de préparer un tome au format CBZ. L'application gère les lots, le suivi et l'historique.

Le pont PC reste nécessaire. Deux modes de livraison sont prévus : transfert direct vers la Kobo, ou dépôt dans Dropbox. Dropbox restera facultatif.

## Installation

L'installation publique via NickelMenu et l'appairage PC sont en préparation. Aucun paquet public validé actuellement.

## État

Le transfert CBZ direct et les tests sur une installation neuve restent à réaliser. La version personnelle en production n'est pas modifiée.

Le code sera publié après contrôle des informations privées, des dépendances et des droits de redistribution.
